# Huella de carbono: ¿quién contamina más?
**Integrantes**:
Jonatan David Macdonal Rodas

Santiago Miranda Cañedo

**Descripción**: Huella de Carbono consiste en un dashboard interactivo desarrollado en React que analiza las emisiones de CO₂ por país entre 2010 y 2023 y las relaciona con la población, el PIB y la felicidad, con el fin de identificar patrones entre desarrollo económico y contaminación y fomentar la reflexión sobre la sostenibilidad global. Los datos provienen de Our World in Data (Global Carbon Budget 2025).
